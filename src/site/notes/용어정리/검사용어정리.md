## 개요

CIS 연동목록에 등재된 **검사항목(총 76종)** 의 영문 약어와 Full Spelling을 진료과별로 정리한 노트다.
연동목록에는 국문 검사명만 있거나 영문 약어만 있는 항목이 섞여 있어, **누락된 영문명·약어는 장비 모델명과 검사 성격을 근거로 보완**했다.

- 원본에 영문 표기가 없어 **보완 기입한 항목**은 `➕` 로 표시
- 원본 표기에 오기(誤記)로 추정되는 항목은 `⚠️` 로 표시하고 정정안을 병기

|---|---|---|

| **IntelliLink** | GE IntelliLink (CGS) | GE 환자감시장치 서버 연동 |
| **PACS** | Picture Archiving and Communication System | 의료영상 저장·전송 시스템 (안저·조영 영상 전송) |

| **유형 E** | Serial 연동 | RS-232 직접 연동 (자동굴절검사 1대) |
