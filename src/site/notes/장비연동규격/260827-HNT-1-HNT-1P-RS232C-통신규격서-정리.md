## 2. 통신 방식 (Introduction)

- 측정 데이터를 외부 PC 또는 장치로 전송하기 위해 `HNT-1 & 1P` 시스템(HNT)은 **RS-232C 시리얼 인터페이스 기반 데이터 통신 프로토콜**을 지원한다.
- 이 프로토콜은 **상대방의 응답을 요구하지 않는 단방향(one way) 전송**이다.
- 데이터 전송을 사용하려면 **HNT 시스템의 User Setup에서 `COM Out` 메뉴를 ON** 으로 설정해야 한다.

## 3. 하드웨어 기본 설정 (Basic Hardware Configuration)

| 항목 | 값 |
|---|---|
| 방향 | One-sided direction (단방향) |
| Action | **After printing** (인쇄 후 전송) |
| Baud Rate | `115200` |
| Data Bit | `8 Bit` |
| Parity | `No` |
| Stop Bit | `1 Bit` |

→ 요약하면 **115200 8N1**, 흐름제어·핀 배열은 문서에 미기재.

---

## 4. 데이터 포맷 (Data Format) — One-way protocol

- HNT 시스템에 **측정 결과가 있는 상태에서 `Print` 키를 누르면** 결과지가 인쇄되고 **동시에 데이터가 전송**된다.
- User Setup에서 각 메뉴 항목을 disable 하면 **인쇄와 전송이 모두 취소**된다.
- 외부 PC/장치와의 통신은 **상호(mutual) 방식이 아니다.** HNT는 아래 데이터 포맷대로 **ASCII 코드 패킷을 한 건씩 순차 전송**하며, 일반적인 `ACK`, `NAK`, `STX` 등의 응답을 **기다리지 않는다.**
- 별도 프로그램 구현 없이도 `DNW` 같은 **일반 터미널 소프트웨어에서 전체 통신 내용을 확인**할 수 있다.

### 4-1. 전송 예시 (원문 4페이지 그대로)

```text
\r\n
NO: ␣21\r\n
DATE: ␣2016/12/14  12:35\r\n
VER: ␣1.0.0\r\n
T-R01: ␣10\r\n
T-R02: ␣18*\r\n
T-R03: ␣10*\r\n
T-R-A: ␣10.0\r\n
P-R01: ␣513\r\n
P-R02: ␣504\r\n
P-R03: ␣476*\r\n
P-R-A: ␣508.5\r\n
T-L01: ␣18\r\n
T-L02: ␣18\r\n
T-L03: ␣16\r\n
T-L04: ␣16\r\n
T-L-A: ␣17.0\r\n
P-L01: ␣531\r\n
P-L02: ␣524\r\n
P-L03: ␣527\r\n
P-L03: ␣528\r\n     ← 원문 그대로 (P-L04 오기로 추정)
P-L-A: ␣527.5\r\n
\r\n
```

> 원문 표기: `␣`(문서에는 `⌒` 형태) = **Space character**, `\r` = Carriage Return, `\n` = Line Feed.

### 4-2. 프레이밍 규칙

- 데이터 전송의 **시작과 끝에 `CR+LF` 한 쌍**을 보내 연결된 장치에 통신의 시작/종료를 알린다.
- **각 데이터 패킷(행)의 끝에도 `CR+LF`** 를 붙인다.
- **데이터 패킷 개수는 좌·우 양쪽의 측정 횟수에 따라 가변**이다.
- **측정 데이터가 없으면 통신 자체가 발생하지 않는다.**

---

## 5. 패킷별 필드 정의 (원문 5페이지)

| Packet | Description |
|---|---|
| `\r\n` | Start-up of data transmission (전송 시작) |
| `NO: 21` | 환자번호 (Patient number) — **최대 5자리** |
| `DATE: 2016/12/14  12:35` | 측정 일시 (년/월/일 시:분) — 날짜 형식은 User Setup의 `Date` 메뉴 옵션에 따라 달라짐 |
| `VER: 1.0.0` | 소프트웨어 버전 |
| `T-R01: 10` / `P-L01: 531` | Measure Type(`T`=Tono, `P`=Pachy) + Measure Side(`R`/`L`) + Measure Count(`01`~`10`) + Measure Data |
| `T-R02: 18*` / `P-R03: 476*` | 위와 동일 + **Asterisk(`*`) = Unreliability Mark(신뢰도 이상 표시)** |
| `T-R-A: 10.0` / `P-L-A: 527.5` | Measure Type + Measure Side + **`A` = 평균값(Average Measure Data)**<br>· `*`가 붙은 측정값은 **평균 계산에서 제외**<br>· 평균값의 소수점 표기는 User Setup의 `Float Average` 옵션에 따라 달라짐 |
| `\r\n` | Close-up of data transmission (전송 종료) |

### 5-1. 키 구성 요약

```text
[Type]-[Side][Count] : [Value][*]
   │       │     │        │    └ 신뢰도 이상 표시(선택)
   │       │     │        └ 측정값
   │       │     └ 01~10 또는 A(평균)
   │       └ R(우안) / L(좌안)
   └ T(Tono, 안압) / P(Pachy, 각막두께)
```

## 6. 원문 검증 메모

### 6-1. 평균값 계산 검증 (`*` 제외 규칙 확인됨)

| 평균 필드 | 원문 값 | 대상 측정값 | 계산 |
|---|---|---|---|
| `T-R-A` | `10.0` | `10`, ~~`18*`~~, ~~`10*`~~ | 10 ÷ 1 = **10.0** ✅ |
| `P-R-A` | `508.5` | `513`, `504`, ~~`476*`~~ | (513+504) ÷ 2 = **508.5** ✅ |
| `T-L-A` | `17.0` | `18`, `18`, `16`, `16` | 68 ÷ 4 = **17.0** ✅ |
| `P-L-A` | `527.5` | `531`, `524`, `527`, `528` | 2110 ÷ 4 = **527.5** ✅ |

→ **`*` 표시 값은 평균에서 제외**된다는 규칙이 예시로 확인된다.

### 6-2. 원문 오기 의심

- 좌안 Pachy 4번째 행이 `P-L03: 528`로 인쇄되어 **`P-L03`이 두 번** 나온다.
- 그러나 평균 `527.5`는 **4개 값의 평균**이므로, 네 번째 행은 **`P-L04`가 맞을 가능성이 높다.**
- 캡처만으로 확정하지 말고 **실장비 출력으로 확인** 필요. 수신기는 중복 키를 즉시 덮어쓰지 말고 **수신 순서를 보존**하도록 구현할 것.

## 7. 연동 구현 시 체크리스트

- [ ] 현장 설치 모델이 `HNT-1`인지 `HNT-1P`인지 확인 (HNT-1은 Pachymeter 없음 → `P-*` 행을 필수로 기대 금지)
- [ ] User Setup의 `COM Out` = ON 여부 확인
- [ ] 전송 트리거가 **수동 `Print` 키**임 → 자동 전송 설정 가능 여부 제조사 확인
- [ ] 연속 `CRLF`(빈 행)를 메시지 경계로 처리, 고정 행 수 가정 금지
- [ ] `*`는 값에서 분리해 `unreliable` 플래그로 저장
- [ ] 체크섬·메시지 ID·ACK가 없음 → **원문 로그 보관 + 중복 감지(환자번호+측정일시+원문 해시) 정책** 필요
- [ ] `NO:`가 **최대 5자리**라 병원 환자번호를 그대로 담지 못할 수 있음 → 매핑 방식 확정
- [ ] 날짜 형식(`Date` 옵션), 평균 소수점(`Float Average` 옵션) 실제 설정값 확인
- [ ] 재출력(Re-print) 시 동일 결과가 재전송되는지 확인
- [ ] 케이블 종류·커넥터 핀 배열·DTE/DCE·흐름제어는 문서 미기재 → 현장 확인
- [ ] 단위(Tono `mmHg`, Pachy `μm`)는 통신 데이터에 없음 → 수신 DB 단위 별도 확정
