## 4. 상관 분석 — 결정적 근거

NET(500Hz)을 1000Hz로 업샘플해 USB와 리드별로 최적 정렬 후 비교했습니다.

| 리드 | 정렬 lag | 정렬 후 corr | **기저선 제거 후 corr** | 기저선 차이 RMS |
|---|---|---|---|---|
| I | +5 ms | 0.9961 | **0.9962** | 8 µV |
| II | +5 ms | 0.9959 | **0.9978** | 13 µV |
| III | +5 ms | 0.9831 | **0.9957** | 15 µV |
| aVR | +5 ms | 0.9970 | **0.9968** | 9 µV |
| aVL | +5 ms | 0.8700 | **0.9848** | 19 µV |
| aVF | +5 ms | 0.9912 | **0.9971** | 15 µV |
| V1 | +5 ms | 0.9090 | **0.9938** | 71 µV |
| V2 | +5 ms | 0.8545 | **0.9760** | 59 µV |
| V3 | +5 ms | 0.9954 | **0.9958** | 17 µV |
| V4 | +5 ms | 0.9731 | **0.9953** | 52 µV |
| V5 | +5 ms | 0.9704 | **0.9937** | 65 µV |
| V6 | +5 ms | 0.9088 | **0.9833** | 112 µV |
| **평균** | | 0.9537 | **0.9922** | |

(기저선 제거 = 0.5 Hz 고역통과. 심전도 신호 성분은 그대로 두고 baseline wander만 걷어냄)

**해석**

- 기저선을 걷어내면 상관이 0.954 → **0.992**로 올라갑니다. 즉 **차이의 대부분이 기저선 변동 하나**입니다.
- 기저선 차이 RMS가 사지유도 8~19 µV(무시 가능), 흉부유도 52~112 µV로 갈립니다. `hipass 0.02 Hz`는 `0.05 Hz`보다 저주파를 2.5배 더 통과시키므로 **예상되는 정상 결과**입니다. V6가 112 µV로 가장 큰데, 진폭 범위 차이(−1075 vs −224)와 정확히 대응합니다.
- 정렬 전 낮았던 aVL(0.87), V2(0.85), V1/V6(0.91)이 모두 0.976~0.994로 회복됩니다.

## 5. 시간축 5 ms 차이 — 파서 원인이 아닙니다

전 리드에서 **균일하게 +5 ms** 오프셋이 관측됩니다. 파서가 원인인지 확인하기 위해 **소스 XML 두 개를 파서와 무관하게 직접 디코딩**해 비교했습니다.

| | 소스끼리 직접 비교 | 출력끼리 비교 |
|---|---|---|
| 최적 lag | **+6 ms** | **+5 ms** |
| 그때의 corr | 0.944 ~ 0.973 | 0.954 (평균) |

**소스 파일 단계에서 이미 5~6 ms 차이가 존재합니다.** 장비가 Network 전송본과 USB 아카이브본을 만들 때 파형 시작점이 몇 밀리초 어긋난 것이며, **파서는 이 차이를 만들지도 키우지도 않았습니다.**

5 ms는 500 Hz 기준 2.5 샘플, 25 mm/sec 인쇄에서 0.125 mm로 육안 식별 불가 수준입니다.

## 8. 아직 남은 것

### P2-4 페이싱 마커 보정 — 여전히 미검증

이번 두 XML도 `pacepulse` 노드가 **0개**입니다(직전 03002771 케이스와 동일). `if(nRealOffset > 0)` 안의 보정 루프가 빈 배열로만 돌았습니다.

**검증 방법**: 테스트용 XML의 `internalmeasurements/crossleadmeasurements/pacepulses` 에 다음을 삽입 후 옵션 ON으로 실행.

```xml
<pacepulses>
  <pacepulse starttime="3000"/>   <!-- 1000Hz 기준 샘플 2000 위치로 이동해야 함 -->
  <pacepulse starttime="500"/>    <!-- 잘려나간 구간 -> 제거되어야 함 -->
</pacepulses>
```

### 그 외 미테스트 시나리오

| # | 시나리오 | 확인 항목 |
|---|---|---|
| 1 | `WaveFormLast10Sec` **OFF** | `nRealOffset[0]`, 0~10초 구간 출력 |
| 2 | 10초 미만 기록(`durationperchannel` 축소) | A-5 clamp 동작, 크래시 없음, 뒷부분 0 |
| 3 | `samplespersecond` 위조(예: 2000) | B-2가 mismatch 검출 → 명시적 실패 |
| 4 | V1.03 / V1.04 / V1.04.02 파일 | A-2 회귀 (샘플 확보 시) |
| 5 | 비압축(`compression != XLI`) 파일 | C-1/C-2 경로 |

### 별개 트랙

직전 회차에서 확인된 `NetHelper::SetExam(), DB.RequestQueryBlock() fail` (코드 16777219) — 오더 매칭/DB 등록 실패. 파싱과 무관하나 별도 확인 필요.
