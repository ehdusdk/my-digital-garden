#강북삼성화성 #LocalCDWExporter #GUID #Content #Interface

[[이슈/이슈 정리\|이슈 정리]]

## 결론
1. 현재 발생한 이슈는 16054E90-CF9A-4E48-9451-027FD4B62302.xml 와 같이  매핑되는 폴더 생성이 안된 것이 문제가 됨 
	1. LocalCDWExpoter가  **\16054E90-CF9A-4E48-9451-027FD4B62302\16054E90-CF9A-4E48-9451-027FD4B62302_CDW.xml** 파일 경로찾아서 수치값을 이용해야하나 생성된 폴더 및 관련 xml 내용이 없어서 발생한 문제로 보임 
		1. 로그를 추가하여 폴더 생성 못한 이유 원인 분석 필요  
	2. 혈압 관련 CISReceiver -> CISNeis 로 인터페이스 용 XML 전달시에 CDW.Content@GUID 값이 누락되어 나오는 것도 확인 
		1. CDW.Content@GUID 추가하도록 코드 수정
		2. CDW.Numeric@GUID, CDW.Numeric@FILE 추가하도록 코드 수정 
## 이슈내용
1. [Defect #155215: [강북삼성병원] 차세대 종건용 NEISLite+LocalCDWExporter 사용 시 간헐적 수치값 누락의 건 - CIS - INFINITT Redmine](https://src.infinitt.com/issues/155215)
2. CDW xml 생성시에  폴더생성되어 Content 및 CDW 관련 XML 이 생성되어야 하나 16054E90-CF9A-4E48-9451-027FD4B62302.xml 에 대한 매핑되는 동일 명의 폴더와 그 폴더 안에  Content, CDW 관련 xml 생성되었어야 하나 생성되지 않음![Pasted image 20260812095956.png](/img/user/Pasted%20image%2020260812095956.png)
3. 어떤 이유인지 확정은 아니지만  CDW 태그 아래 Numeric Guid 값이 넘어오지 않는 상태 
	1. 이부분은  CIS Recever + CISNeis[Lite] + LocalCDWExporter 조합시에 큰 문제가 되진 않는다. 
	2. Content@Guid 값으로  CDW 값을 쫓아가서 처리 가능 함!
4.  ![Pasted image 20260812100003.png](/img/user/Pasted%20image%2020260812100003.png)
5. 정상적으로 보이는 xml  Numeric  태크 값에 guid ,  file 속성 값이 채워져 있음

## 분석내용 요약
1. cdw xml 정보를 가지고 있는 guid\guid_CDW.XML 존재하지 않았음 
	1. 관련 로그 보강 
2. 현재 CISRECEIVER 버전으로 혈압이나 청력  관련 CISRECEIVER -> CISNEIS  인터페이스용 XML 전달 시에  CDW.Content@GUID 값이 누락되어 있음을 확인 이부분도 문제가 될 수 있다고 판단 guid 값을 표시하도록 추가 했음
3. 현재로직
	1. CISReceiver와 CISNEIS  인터페이스 xml에  CDW.Content@GUID 값을 이용하여 CISNEIS에서 매칭을 수행시에 생성되는 MatchedInfo.xml에  CDWGUID 값을 추가 한다.
	2. LocalCDWExport는  MatchedInfo.xml 확인하고 CDWGUID 값으로  현재  CIS Receiver 생성된 CDW 관련  {CDWGUID}.xml 과 {CDWGUID}\CDWGUID_CDW.xml 찾아서 수치값을 연동하도록 처리 한다. 
4. 현재 이슈는 혈압이나 청력 검사시에  특정 케이스에 {CDWGUID}.xml 정상적인 XML 형태가 아니고 (InstanceType 태그 누락, CDW.Content, CDW.Numeric  속성 값 누락) {CDWGUID}\CDWGUID_CDW.xml 파일도 존재하지 않는 문제 임을 확인
