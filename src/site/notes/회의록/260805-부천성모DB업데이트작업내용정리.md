## 📌 주요 작업 및 진행 내용

### 1. DB 업데이트 검증
- DB 업데이트 진행 시 `PKGSYSTEMPROFILE`, `PKG~~Update` 관련 Body golden 변경 이력이 보이지 않아 이력 체크 진행 (Body 부분 정상 체크 확인 완료).

### 2. CIS Receiver ECG Design 변경 및 재매칭
- CIS Receiver 교체 시 ECG Design이 12Ch로 되어 있었으나, 병원 관계자 요청으로 **3Ch + 1Rh**로 변경 적용.
- DB 서버 이전(18:42) 이후 발생 환자에 대해 CISNEIS에서 JPG 재매칭 수행하여 처리 완료.

### 3. CISInbroker / CISOutbroker 정상 동작 작업
- `T_BrokerWorkerJob` 테이블의 `BWJ_KEY` 조정을 위해 Deacth 관련 상태 내용 제거 작업 진행.
- 서버 1호기/2호기 CISInbroker / CISOutbroker Active/Standby 상태를 맞추기 위해 서비스 재시작 후 상태 정상 동작 확인.

### 4. CIS App 실행 유지 및 미실행 현황
- **기존 버전 실행 유지**:
  - `DB_Linker`
  - `VitalSite`
  - `Inboundbroker` (2호기)
- **기존 버전 실행 제외 / 미동작**:
  - `MixSite` (로그 확인 결과 미동작으로 파악됨)
  - `StorageSrv` (2호기)
